# 리미터(soft clip) 비교 샘플 (#20)

MusicGen 출력 중 peak가 가장 큰 곡(`humix_test_5_loop`, 30초, 로컬 MPS 생성, float32 저장 원본 peak 1.774)을 두 방식으로 PCM 16bit 저장한 결과입니다.

| 파일 | 처리 |
|---|---|
| `humix_test_5_loop_limited.wav` | `audio_output.save_output_wav` (기준 0.9 soft clip → PCM16) |
| `humix_test_5_loop_hardclip.wav` | 기존 방식처럼 1.0에서 잘라서 PCM16 저장 |

## 수치
| 항목 | 값 |
|---|---|
| 1.0 초과 샘플 | 482개 (0.05%), 230회, 가장 긴 구간 0.38ms |
| 리미터가 바꾼 샘플(>0.9) | 1,879개 (0.20%) |
| 최대치(≥0.999)에 붙은 샘플 | limited 91 / hardclip 487 |
| 전체 RMS 변화 | limited -0.008 dB / hardclip -0.007 dB |
| 두 파일 간 0.001 이상 차이 나는 샘플 | 1,132개 (0.12%), 최대 차이 0.024 |

같은 조건의 다른 두 곡도 결과가 비슷했습니다.

| 곡 | peak | 바꾼 샘플 | 최대치에 붙은 샘플 (limited / hardclip) | RMS 변화 |
|---|---|---|---|---|
| `humix_test_6_two_stage` | 1.503 | 0.13% | 16 / 197 | -0.004 dB |
| `humix_test_2_extended_range` | 1.150 | 0.05% | 0 / 59 | -0.0005 dB |

## 정리
- 0.9 이하 샘플은 그대로이고(16bit 양자화 오차만 있음), 곡 전체 음량은 사실상 변하지 않음
- 0.9~1.1 근처 값에서는 리미터가 부드럽게 눌러 줌. 청취 시 리미터 쪽이 약간 더 부드럽게 들림
- 1.3 이상처럼 크게 넘은 피크는 두 방식 모두 최대치 근처로 납작해짐 → 피크 모양까지 살리려면 이슈의 대안(고정 배율 후 리미터)이 필요하며, 서버 GPU 출력의 peak 분포를 보고 결정
